## Pipeline to execute

Run these commands in order. Each agent invocation is an independent step.

### Step A — Sync (pre-condition)

```
/bam-sync
```

Record the resolved commit SHA of `../bam-masterdata`. Store in `runs/<ts>/bam_sha.txt`.

### Step B — Analyze PRD

```
/bam-analyze-prd evals/regressions/BAM_PRD_Workflow_FB72_original.md
```

Expected output: `generated/welded_fatigue/gap-report.md` (or the prd-stem equivalent).

Capture:
- `generated/<prd-stem>/CATALOG.md` → `runs/<ts>/output/CATALOG.md`
- `generated/<prd-stem>/requirements.json` → `runs/<ts>/output/requirements.json`
- `generated/<prd-stem>/gap-report.md` → `runs/<ts>/output/gap-report.md`

### Step C — Generate types

```
/bam-generate-types BAM_PRD_Workflow_FB72.md
```

Capture:
- `generated/<prd-stem>/datamodel/vocabularies.py` → `runs/<ts>/output/vocabularies.py`
- `generated/<prd-stem>/datamodel/object_types.py` → `runs/<ts>/output/object_types.py`

### Step D — Generate notebook

```
/bam-generate-notebook BAM_PRD_Workflow_FB72.md
```

Capture:
- `notebooks/<prd-stem>_provisioning.ipynb` → `runs/<ts>/output/provisioning.ipynb`

### Step E — Generate parser

```
/bam-generate-parser BAM_PRD_Workflow_FB72.md
```

Capture:
- `generated/<prd-stem>/parsers/src/*/parser.py` → `runs/<ts>/output/parser.py`
- `generated/<prd-stem>/parsers/tests/test_parser.py` → `runs/<ts>/output/test_parser.py`

Evaluate all captured outputs against `evals/regressions/_score.md`.

Record results in `runs/<ts>/regression-results.md`.

## Notes

- This task runs after every `/bam-improve` invocation (Step 7 of the Karpathy loop).
- The task is deterministic given the same `../bam-masterdata` SHA — byte-identical outputs are expected on re-runs.
- If outputs differ between runs at the same SHA, that indicates non-determinism in an agent (a bug to fix, not to ignore).
